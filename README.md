# Pelatihan Generative AI with Large Language Models

Repository ini berisi submission dan materi terkait **Pelatihan Generative AI with Large Language Models (PGABL)** oleh Muhammad Bazwa Arigusna.

## 📁 Struktur Direktori

- `Fine_tuning_submission_PGABL_Muhammad_Bazwa_Arigusna.ipynb`: Notebook eksperimen fine-tuning model (LLaMA-3-8B Indonesian SFT menggunakan Unsloth).
- `RAG_submission_PGABL_Muhammad_Bazwa_Arigusna.ipynb`: Notebook implementasi Retrieval-Augmented Generation (RAG) menggunakan LangChain & ChromaDB.
- `requirements.txt`: Daftar dependencies library yang dibutuhkan.
- `link_huggingface.txt`: Tautan model yang telah diunggah ke Hugging Face.
